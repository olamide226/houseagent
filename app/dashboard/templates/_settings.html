How to set up the phone
  1. In the Shortcuts app on {{ presence.name }}'s iPhone, make an automation for each place. The trigger is Arrive at the place, set to run without asking.
  2. Its one action is Get Contents of URL with this link, method POST, and a JSON request body with two text fields: event = enter and place = the place's name exactly as listed under Places.
  3. For home, add one more with the trigger Leave and event = exit.
