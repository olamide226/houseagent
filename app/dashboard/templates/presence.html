Set it up, one shop at a time

You need your iPhone and its Shortcuts app. Do the three steps for one shop, then come back for the next.

  1. Copy the link for the shop. {% for name, link in shops %}{{ copy(name, link) }}{% else %} {{ agent }} does not know your shops yet. Tell it in your chat where you shop, for example "we shop at Tesco and Lidl", then open this page again. {% endfor %}
  2. {% if shortcut %} Add the shortcut. Tap the button, then Get Shortcut. When it asks for the link, paste what you copied. {{ icon("plus") }}Get the shortcut Adding a second shop? First rename the shortcut you already have to its shop's name: open it, tap the arrow beside its name, then Rename. {% else %} Make a shortcut for the shop. Tap the button: the Shortcuts app opens on a new shortcut. {{ icon("plus") }}Start a new shortcut Tap Add Action, search for Get Contents of URL and tap it. Tap URL in it and paste what you copied. Leave the rest as it is. Tap New Shortcut at the top, then Rename, and call it after the shop. {% endif %}
  3. Tell your iPhone when to use it. Open the shortcut in the Shortcuts app and tap Edit, then Automation. Choose Arrive, tap Choose and find the shop. Tap Edit again, open Privacy and turn on Allow Running When Locked, so it runs by itself.
    My iPhone does not show Automation there On an iPhone that has not been updated for a while: in the Shortcuts app tap Automation, then +, and choose Arrive. Tap Choose, find the shop and tap Next. Pick the shortcut you made. Then tap the new automation, turn off Ask Before Running and tap Don't Ask.

To try it, put something on the shopping list and run the shortcut once: tap it in the Shortcuts app. The list for that shop should arrive in your chat with {{ agent }}.

For you, as whoever set up {{ agent }}{{ icon("down", "chev") }}
Nobody has to build or share anything first: each person makes their own shortcut with the steps above. Apple gives no way to put a shortcut or an automation on someone else's iPhone, so each person does these steps on their own phone, once per shop. Not tried on an iPhone yet. The steps follow Apple's Shortcuts User Guide for iOS 27 and iOS 26, and Apple renames these screens between versions. A shortcut made this way asks with GET, the action's own setting; {{ agent }} counts a GET or a POST of a shop's link as arriving. You can still share one shortcut so the family can skip the second step: PRESENCE_SHORTCUT_URL, described in the guide that came with {{ agent }} (docs/presence.md).
