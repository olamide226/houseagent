The list when you reach a shop

This is your personal link. It lets your iPhone tell {{ agent }} when you arrive at a shop, so the shopping list for that shop is waiting for you.

It is optional. Everything else works without it, and you can set it up any time.

Set it up, one shop at a time

You need your iPhone and its Shortcuts app. Do the three steps for one shop, then come back for the next.

  1. Copy the link for the shop. {% for name, link in shops %}{{ copy(name, link) }}{% else %} {{ agent }} does not know your shops yet. Tell it in your chat where you shop, for example "we shop at Tesco and Lidl", then open this page again. {% endfor %}
  2. {% if shortcut %} Add the shortcut. Tap the button, then Get Shortcut. When it asks for the link, paste what you copied. {{ icon("plus") }}Get the shortcut Adding a second shop? First rename the shortcut you already have to its shop's name: open it, tap the arrow beside its name, then Rename. {% else %} Make the shortcut. You do this part once, and share it so nobody else in the family has to.
    How to make and share it
    1. In the Shortcuts app, make a new shortcut and add the action Get Contents of URL.
    2. Paste the link you copied where it says URL. Tap Show More and change Method to POST. Leave the rest as it is.
    3. Run it once. If something is on the list for that shop, the list arrives in your chat.
    4. To share it: open the shortcut's details, tap Setup, then Add New Question. Choose the link you pasted and type the question "Paste the link you copied for this shop".
    5. Share it with Copy iCloud Link, and save that link as PRESENCE_SHORTCUT_URL where {{ agent }} is set up. From then on this page gives everyone a button in place of these steps.
    {% endif %}
  3. Tell your iPhone when to use it. Open the shortcut in the Shortcuts app and tap Edit, then Automation. Choose Arrive, tap Choose and find the shop. Tap Edit again, open Privacy and turn on Allow Running When Locked, so it runs by itself.
    My iPhone does not show Automation there On an iPhone that has not been updated for a while: in the Shortcuts app tap Automation, then +, and choose Arrive. Tap Choose, find the shop and tap Next. Pick the shortcut you added. Then tap the new automation, turn off Ask Before Running and tap Don't Ask.

To try it, put something on the shopping list and run the shortcut once. The list for that shop should arrive in your chat with {{ agent }}.
